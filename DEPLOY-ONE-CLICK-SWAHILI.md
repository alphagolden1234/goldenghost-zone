# Golden Ghost V37 — Deploy ya hatua chache

## GitHub root (MUHIMU)

Repository root lazima iwe na:

- `public/index.html`
- `public/manifest.webmanifest`
- `public/service-worker.js`
- `server.js`
- `db.js`
- `package.json`
- `render.yaml`

Usiwe na folder la ziada kama `golden-ghost-v37/public/...` ndani ya repository.

## Render

- Build: `npm install --no-audit --no-fund`
- Start: `npm start`
- Plan: `Free`
- Health: `/healthz`
- `PORT` inaachwa Render i-set yenyewe.
- Weka `SESSION_SECRET` kwenye Environment Variables.

## PWA

Baada ya kupata HTTPS URL ya Render, fungua Chrome/Edge/Safari na chagua Install / Add to Home Screen.
